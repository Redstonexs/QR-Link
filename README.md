# 📱 批量二维码生成器 (QR-Link Generator)

一个简洁高效的Web应用，可以将数百个网址批量转化成可扫描的二维码，并按阿拉伯数字排序导出。

## ✨ 功能特性

- 🚀 **批量生成**：支持一次性输入数百个网址，批量生成二维码
- 📋 **简单易用**：只需粘贴网址列表，每行一个URL即可
- 🔢 **数字排序**：所有二维码按1、2、3...顺序编号
- 💾 **灵活导出**：
  - 单个下载：可单独下载任意一个二维码（格式：001.png, 002.png...）
  - 批量下载：一键打包下载全部二维码为ZIP文件
- 🎨 **现代界面**：响应式设计，支持桌面和移动设备
- ⚡ **纯前端**：无需服务器，在浏览器中直接运行

## 🚀 快速开始

### 方法一：直接打开
1. 下载或克隆本项目
2. 用浏览器打开 `index.html` 文件即可使用

### 方法二：使用本地服务器（推荐）
```powershell
# 如果安装了Python
python -m http.server 8000

# 如果安装了Node.js
npx serve

# 如果安装了PHP
php -S localhost:8000
```

然后在浏览器中访问 `http://localhost:8000`

## 📖 使用说明

1. **输入网址**
   - 在文本框中粘贴您的网址列表
   - 每行一个URL，例如：
     ```
     https://example.com
     https://google.com
     https://github.com
     ```

2. **生成二维码**
   - 点击"生成二维码"按钮
   - 系统会自动为每个网址生成对应的二维码
   - 二维码按1、2、3...顺序编号

3. **下载二维码**
   - **单个下载**：点击每个二维码下方的"下载"按钮
   - **批量下载**：点击"下载全部二维码"按钮，获得ZIP压缩包

## 🛠️ 技术栈

- **Vue.js 3**：前端框架
- **QRCode.js**：二维码生成库
- **JSZip**：ZIP文件生成
- **FileSaver.js**：文件下载
- **原生CSS**：响应式样式设计
